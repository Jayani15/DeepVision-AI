# GAN - Image Generation

This module implements a Deep Convolutional Generative Adversarial Network
(DCGAN) for generating synthetic CIFAR-10-like images.

## Architecture

The GAN consists of two neural networks:

### Generator
Takes a 100-dimensional random latent vector and generates a 32x32 RGB image.

### Discriminator
Receives an image and learns to distinguish between real CIFAR-10 images
and images generated by the Generator.

## Pipeline

Random Noise
    ↓
Generator
    ↓
Generated Image
    ↓
Discriminator
    ↓
Real / Fake Feedback
    ↓
Adversarial Training

## Dataset

CIFAR-10

- Image size: 32x32
- Channels: 3
- Training images: 50,000
- Classes: 10

## Training Configuration

| Parameter | Value |
|---|---|
| Latent Dimension | 100 |
| Batch Size | 64 |
| Epochs | 20 |
| Optimizer | Adam |
| Learning Rate | 0.0002 |
| Beta 1 | 0.5 |
| Beta 2 | 0.999 |
| Device | CPU |

## Results

The Generator learned meaningful visual patterns from CIFAR-10.
Generated samples and training loss curves are available in the `results/`
directory.

## Running

From the DeepVision-AI root:

```bash
python -m backend.models.gan.train
```

### Generate new images using the trained Generator:

```bash
python -m backend.models.gan.generate
```

### Run evaluation:

```bash
python -m backend.models.gan.evaluate
```
